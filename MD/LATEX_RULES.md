# Правила использования LaTeX в Markdown Editor

## Когда использовать обрамление $...$ или $$...$$

### ✅ Простые команды БЕЗ обрамления (работают автоматически)

Эти команды можно писать без `$...$`:

```markdown
Единицы: 10 \text{см}, 5 \text{кг}
Простые дроби: \frac{1}{2}, \frac{3}{4}
Векторы: \vec{a}, \vec{F}
Стрелки: \implies, \iff, \cdot, \times
Греческие буквы: \alpha, \beta, \gamma
```

### ⚠️ Сложные конструкции С обрамлением (обязательно!)

Для этих случаев **обязательно** используйте `$...$`:

#### 1. Вложенные команды
```markdown
❌ Неправильно: \gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}
✅ Правильно: $\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}$
```

#### 2. Команды с опциональными аргументами
```markdown
❌ Неправильно: \sqrt[3]{8}
✅ Правильно: $\sqrt[3]{8}$
```

#### 3. Boxed с вложенными командами
```markdown
❌ Неправильно: \boxed{v = \sqrt{\frac{2E}{m}}}
✅ Правильно: $\boxed{v = \sqrt{\frac{2E}{m}}}$

❌ Неправильно: \boxed{\text{Скорость } = 100 \text{ м/с}}
✅ Правильно: $\boxed{\text{Скорость } = 100 \text{ м/с}}$
```

#### 4. Команды с индексами и степенями
```markdown
❌ Неправильно: \sum_{i=1}^{n} i
✅ Правильно: $\sum_{i=1}^{n} i$

❌ Неправильно: \int_{0}^{\infty} e^{-x} dx
✅ Правильно: $\int_{0}^{\infty} e^{-x} dx$
```

## Рекомендации

### Для inline формул (в строке текста)

**Простые случаи** - можно без обрамления:
```markdown
Скорость света равна 3 \times 10^8 \text{м/с}
Вектор \vec{a} направлен вверх \uparrow
```

**Сложные случаи** - используйте `$...$`:
```markdown
Скорость $v = \sqrt{\frac{2E}{m}}$ м/с
Коэффициент $\gamma = \frac{1}{\sqrt{1 - v^2/c^2}}$
```

### Для display формул (отдельным блоком)

Всегда используйте `$$...$$` или `\[...\]`:

```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

\[
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\]
```

## Примеры из физики

### ✅ Правильное использование

```markdown
Второй закон Ньютона: \vec{F} = m\vec{a}

Кинетическая энергия: $E_k = \frac{mv^2}{2}$

Преобразование Лоренца с $\gamma = \frac{1}{\sqrt{1 - v^2/c^2}}$

Ответ: $\boxed{v = 100 \text{ м/с}}$
```

### ❌ Неправильное использование

```markdown
Кинетическая энергия: E_k = \frac{mv^2}{2}  ← нет обрамления для сложной формулы

Преобразование Лоренца с \gamma = \frac{1}{\sqrt{1 - v^2/c^2}}  ← вложенные команды без $...$

Ответ: \boxed{v = 100 \text{ м/с}}  ← boxed с текстом без $...$
```

## Общее правило

**Если формула содержит:**
- Вложенные фигурные скобки `{...{...}...}`
- Опциональные аргументы `[...]`
- Индексы и степени `_{}` или `^{}`
- Несколько команд подряд

**→ Используйте обрамление `$...$` или `$$...$$`**

**Если формула простая:**
- Одна команда без вложенности
- Простой текст или символ

**→ Можно без обрамления**
