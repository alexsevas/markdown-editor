v0.1.4
1. Исправление отображения MathJax-формул
- Добавлены CSS-правила для корректного отображения MathJax в обеих темах:
  - Прозрачный фон для всех контейнеров (`mjx-container`, `.MathJax` и дочерних элементов).
  - Цвет текста в темной теме изменён на `#e0e0e0`.
  - Исправлены визуальные артефакты для:
    - Векторов (`mjx-stretchy-h`, `mjx-stretchy-v`);
    - Корней (`mjx-surd`);
    - Рамок/боксов (`mjx-box`, `mjx-mrow`).
- Стили применены глобально ко всем соответствующим элементам MathJax.

2. Выравнивание display-формул
- Формулы в тегах `\[ ... \]` теперь выравниваются по **левому краю**, а не по центру.
- Реализовано в `editor.py` (около строки 790).

3. Стилизация заголовков
- Заголовки (`#`, `##` и т.д.) больше не отображаются синим цветом.
- Их цвет теперь соответствует основному тексту:
  - Светлая тема: `#333`;
  - Темная тема: `#e0e0e0`.

4. Исправление экспорта PDF в темной теме
- Ранее PDF при экспорте с темной темой содержал смесь темных и светлых фонов, что делало его нечитаемым при печати.
- Добавлен медиа-запрос `@media print`, принудительно применяющий **светлую тему при печати**:
  - Белый фон;
  - Черный текст;
  - Независимо от текущей темы в редакторе.

5. Поддержка локального контента с удалёнными ресурсами (MathJax CDN)
- В упакованной версии (`exe`) QWebEngineView блокировал загрузку MathJax с CDN.
- Включены настройки WebEngine в `editor.py`:
  - `LocalContentCanAccessRemoteUrls = True`;
  - `JavascriptEnabled = True`;
  - `LocalStorageEnabled = True`.

6. Синтаксическая подсветка изображений
- HTML-теги `<img>` и Markdown-изображения `![...]()()` теперь корректно выделяются **синим цветом**.
- Поддержка синтаксиса проверена и подтверждена.



v0.1.2
1. Добавлен пункт меню "Save as PDF..." в меню File с горячей клавишей Ctrl+P

2. Добавлены необходимые импорты:
   - QWebEngineSettings для настроек веб-движка
   - QMarginsF для отступов страницы
   - QPrinter для печати
   - QPageLayout, QPageSize для настройки страницы

3. Реализован метод save_as_pdf():
   - Предлагает имя файла на основе текущего markdown файла
   - Открывает диалог сохранения файла
   - Настраивает layout страницы (A4, портретная ориентация, отступы 15мм)
   - Использует асинхронный метод printToPdf() с callback
   - Обрабатывает ошибки и показывает статус в статус-баре
   - Сохраняет PDF со всем содержимым preview (включая LaTeX, изображения, стили)

4. Особенности реализации:
   - Асинхронность: printToPdf() работает асинхронно, используется callback для обработки результата
   - Полное содержимое: PDF включает все что отображается в preview - LaTeX формулы (отрендеренные MathJax), изображения, таблицы, код с подсветкой
   - Настройка страницы: A4 формат с отступами для удобного чтения
   - Обработка ошибок: Показывает диалог с ошибкой если что-то пошло не так

5. Как работает:
   - Пользователь выбирает File → Save as PDF...
   - Открывается диалог выбора места сохранения
   - Показывается статус "Exporting to PDF..."
   - QWebEngineView рендерит текущее содержимое preview в PDF
   - PDF сохраняется в выбранный файл
   - Показывается сообщение об успешном сохранении

v0.0.7
--------
1. Упрощение редактора
- Удалена синтаксическая подсветка Markdown.
- Весь текст отображается моноширинным шрифтом **Consolas 11pt**.
- Внешний вид приведён к стилю обычного блокнота.

2. Синхронизация прокрутки
- Реализована **пропорциональная синхронизация** между редактором (слева) и предпросмотром (справа).
- Добавлена задержка **100 мс** для плавности.
- Используется флаг `sync_scroll_enabled` для предотвращения рекурсии.
- Реализованы методы:
  - `sync_editor_to_preview()` — синхронизация из редактора в предпросмотр.
  - `sync_preview_to_editor()` — заготовка для обратной синхронизации.
- Используется JavaScript в WebView через `runJavaScript()` для управления прокруткой.

3. Номера строк и улучшенный редактор
- Создан класс `LineNumberArea`:
  - Отображает номера строк с помощью `QPainter`.
  - Поддерживает светлую и тёмную темы.
- Создан класс `TextEditWithLineNumbers` (на основе `QPlainTextEdit`):
  - Автоматически управляет областью номеров строк.
  - Подсвечивает текущую строку (цвет зависит от темы).
  - Обрабатывает прокрутку и изменение размера.
- Номера строк:
  - Выравниваются по правому краю.
  - Ширина области адаптируется под количество строк.
  - Используется тот же шрифт (`Consolas 11pt`), что и в основном тексте.

4. Стилизация интерфейса под темы
- **Тёмная тема**:
  - Меню, выпадающие списки и строка состояния: белый текст на тёмно-сером фоне.
  - Цвета палитры (`Light`, `Midlight`, `Dark`, `Mid`, `Shadow`) настроены корректно.
  - Исправлен цвет `HighlightedText` (теперь белый).
- **Светлая тема**:
  - Чёрный текст на светлых фонах с аккуратными границами.
- Эффекты при наведении и нажатии добавлены для обоих тем.

5. Улучшения отображения блоков кода
- Устранены большие отступы:
  - `margin: 20px 0` → `margin: 0`
  - `padding: 15px` → `padding: 10px`
- Фоны блоков кода теперь гармонируют с темой:
  - **Тёмная тема**: `#1a1a1a` (фон), `#e0e0e0` (текст), inline-код — розовый (`#ff9ea8`).
  - **Светлая тема**: `#f0f0f0` (фон).
- Добавлено `!important` ко всем стилям тёмной темы, чтобы избежать перезаписи

v 0.0.2
--------
Что изменилось:
- Улучшенное определение кодировки:
- Сначала проверяем наличие BOM (Byte Order Mark) для UTF-8
- Если уверенность chardet ниже 70% или определена ASCII, но файл содержит не-ASCII символы
- Автоматически пробуем распространённые кодировки для кириллицы:
   - cp1251 (Windows-1251) - основная кодировка для русского в Windows
   - koi8-r - альтернативная кодировка для кириллицы
   - utf-8 - как fallback
   - latin1 - для общего случая

Безопасное чтение:
- Если ни одна кодировка не подошла, используем errors='replace' чтобы избежать падения программы
- Проверяем первые 1000 байт на наличие не-ASCII символов
