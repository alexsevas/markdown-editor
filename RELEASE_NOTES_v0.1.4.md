# Release Notes - Markdown Editor v0.1.4

## 🎨 Новые возможности

### Улучшенная подсветка синтаксиса
- ✅ Добавлена подсветка HTML `<img>` тегов синим цветом
- ✅ Markdown изображения `![alt](url)` теперь также выделяются синим
- ✅ Единообразное отображение всех типов изображений в редакторе

## 🔧 Технические изменения

### highlighter.py
- Добавлен отдельный формат `image_format` для изображений
- HTML теги `<img>` с любыми атрибутами выделяются синим цветом
- Markdown изображения выделяются тем же синим цветом
- Поддержка как светлой, так и темной темы

## 📝 Примеры поддерживаемых форматов

**Markdown изображения:**
```markdown
![Описание](путь/к/изображению.png)
```

**HTML изображения:**
```html
<img src="image.png" />
<img width="720" alt="01" src="20251014_КР1/01.png" />
```

## 🎯 Улучшения UX
- Визуальное выделение изображений помогает быстрее ориентироваться в документе
- Синий цвет интуитивно ассоциируется с медиа-контентом
- Согласованность с выделением ссылок
