# Простой редактор Markdown с поддержкой LaTeX

Я создал полноценный редактор Markdown с функцией предварительного просмотра, подсветкой синтаксиса и поддержкой LaTeX.  
Это приложение использует PyQt5.

## Требования

Перед запуском приложения необходимо установить следующие пакеты:

```bash
pip install PyQt5 PyQtWebEngine markdown chardet
```

## Возможности

- Двухпанельный интерфейс: слева редактирование, справа предварительный просмотр (с регулируемым разделителем)
- Подсветка синтаксиса: собственный класс `MarkdownHighlighter` для визуального выделения элементов Markdown
- Предварительный просмотр в реальном времени: автоматическое обновление с использованием таймера задержки (debounce) для повышения производительности
- Поддержка LaTeX: интеграция MathJax для отображения математических формул
- Определение кодировки: используется библиотека `chardet` для автоматического определения кодировки файлов при открытии
- Полноценное меню: пункты меню «Файл», «Правка», «Вид» и «Справка» с соответствующими действиями
- Горячие клавиши: реализованы все стандартные сочетания (Ctrl+C, Ctrl+V, Ctrl+S и т.д.)

Приложение реализует собственный класс `MarkdownHighlighter`, унаследованный от `QSyntaxHighlighter`, чтобы обеспечить подсветку синтаксиса для Markdown-контента. Это даёт визуальные подсказки в редакторе, похожие на те, что используются на платформах для Markdown.

Для панели предпросмотра используется `QWebEngineView` для отображения преобразованного HTML с корректным стилем и интеграцией MathJax для формул LaTeX.

Приложение обрабатывает разные текстовые кодировки с помощью библиотеки `chardet`, чтобы обеспечить корректное отображение всех специальных символов.

Все пункты меню имеют соответствующие горячие клавиши, что делает использование приложения эффективным без мыши.

## Поддержка LaTeX в Markdown Editor

### Поддерживаемые форматы LaTeX формул

1. **Inline формулы (в строке текста)**
   - Стандартный синтаксис: `$формула$`  
     Пример: `$E = mc^2$` → $E = mc^2$
   - LaTeX синтаксис: `\(формула\)`  
     Пример: `\(x^2 + y^2 = r^2\)` → \(x^2 + y^2 = r^2\)

2. **Display формулы (отдельным блоком)**
   - Двойной доллар: `$$формула$$`  
     $$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$
   - LaTeX синтаксис: `\[формула\]`  
     \[
     \sum_{i=1}^{n} i = \frac{n(n+1)}{2}
     \]

3. **Одиночные LaTeX команды (без обрамления)**  
   Редактор автоматически распознаёт и отображает LaTeX команды даже без `$...$`:

   - **Текст**  
     `\text{см}` → единицы измерения  
     `\text{м/с}` → метры в секунду

   - **Дроби**  
     `\frac{1}{2}` → ½  
     `\frac{a}{b}` → дробь

   - **Векторы**  
     `\vec{a}` → вектор a  
     `\overrightarrow{AB}` → вектор AB  
     `\overleftarrow{CD}` → вектор CD влево

   - **Стрелки и операторы**  
     `\implies` → ⇒  
     `\iff` → ⇔  
     `\cdot` → ·  
     `\times` → ×  
     `\uparrow` → ↑  
     `\downarrow` → ↓

   - **Корни**  
     `\sqrt{2}` → √2  
     `\sqrt[3]{8}` → ³√8

   - **Надчеркивание**  
     `\overline{AB}` → черта над AB  
     `\underline{text}` → подчеркивание  
     `\hat{x}` → шляпка над x  
     `\bar{y}` → черта над y  
     `\tilde{z}` → тильда над z

   - **Рамки**  
     `\boxed{x = 5}` → результат в рамке  
     `\boxed{E = mc^2}` → формула в рамке

   - **Греческие буквы**  
     `\alpha, \beta, \gamma, \delta, \theta, \pi, \sigma, \omega`  
     `\Delta, \Gamma, \Lambda, \Omega, \Sigma, \Phi, \Psi`

   - **Специальные символы**  
     `\infty` → ∞  
     `\partial` → ∂  
     `\nabla` → ∇  
     `\hbar` → ℏ

### Примеры использования

**Физика**  
Второй закон Ньютона: \vec{F} = m\vec{a}  
Скорость света: $c = 3 \times 10^8$ \text{м/с}  
Кинетическая энергия:  
$$E_k = \frac{mv^2}{2}$$

**Математика**  
Теорема Пифагора: $a^2 + b^2 = c^2$  
Квадратное уравнение:  
\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]  
Ответ: \boxed{x = 42}
